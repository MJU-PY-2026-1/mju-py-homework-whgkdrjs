# 🐍 [2026-01] 나만의 파이썬 소프트웨어 개발 프로젝트

## 1. 시나리오 제목
* 대학생 주식투자자를 위한 포트폴리오 수익률 관리 프로그램
<br>


## 2. 시나리오 (5~10줄)
* (이곳에 한 학기 동안 개발할 프로그램의 전체 시나리오를 개괄적으로 요약합니다.)
* (예시) 이 프로그램은 대학생 주식투자자들의 포트폴리오 수익률을 관리해주는 프로그램입니다.
* 가장 먼저 프로그램에 매수한 주식종목의 이름과 매수가격,현재가격,매수한 주식의수량 같은 정보를 입력하는 것으로 프로그램이 시작됩니다. 그다음에는 프로그램에 입력된 정보을 모두 합쳐서 프로그램 사용자의 수익률이 얼마인지 계산합니다. 이렇게 계산된 수익률이 양수(플러스)면 @@% 수익 중! 이라는 메세지를 띄워주고, 수익률이 음수(마이너스)라면 @@% 손실 중ㅠㅠ 이라는 메세지를 띄워줍니다. 수익률이 일정 수준이상을 넘거나 손실률이 일정 수준이상을 넘는다면 매도 추천 메세지를 띄워 사용자의 손해를 최소화 시킵니다. 한개의 주식종목뿐만 아니라 여러개의 종목을 리스트에 저장하여 여러 종목의 종합 수익률도 계산하여 알려주고, 여러 사용자의 포트폴리오의 수익률도 리스트에 저장하여 많은 사람들의 주식 포트폴리오 수익률을 보고 공유할수 있는 시스템을 만들 예정입니다. 프로그램을 종료하기전 까지 여러개의 종목을 계속해서 입력 받을수있도록, 한 사람의 수익률이 아닌 다른 사용자의 수익률도 저장할수 있는 프로그램을 구축하겠습니다.

<br>


## 3. 예상 기능 및 메뉴 (최소 5개)
(예시)
1. 신규 프로그램 사용자 등록(사용자 명, 매수한 주식 종목명, 매수단가,현재단가, 매수한 주식수량등)
2. 등록된 정보를 통한 수익률 계산
3. 수익률에 따른 메세지 출력
4. 수익률에 따른 매도 추천 메세지 출력
5. 여러 종목에 대한 종합 수익률 계산 및 메세지 출력
6. 여러 사용자의 수익률 정보 저장 및 출력
7. 프로그램 종료

# 🚀 [버전별 개발 일지 & AI 협업 기록]

## 🟦 [1차 과제: V1.0] 시나리오 기획
    
### **🤖 AI 파트너십 과정**
(예시)
 1. **내용 1 : 주식과 관련된 프로그램 컨셉 도출**
    * **프롬프트 요약:** ""주식관련된 파이썬 프로그램을 만들고 싶어. 강의시간에 배운 성적관리 프로그램이랑 비슷한 형식인 컨셉 추천해줘.""
    * **적용 내용:** AI가 제안한 여러 아이디어 중 수익률 관리 프로그램이 강의 시간에 배웠던 내용과 많이 유사하기도 하면서 제가 관심있는 주식과도 제일 잘 맞는 컨셉이라고 생각해서 주식 포트폴리오 수익률 관리 프로그램을 시나리오로 선택했습니다.
 2. **내용 2 : 로드맵 도출**
    * **프롬프트 요약:** "1차 과제 필수 요건(변수 5개, 자료형 3개 이상)을 나의 시나리오에 적용 시키려면 어떻게 해야할까?
    * **적용 내용:** 사용자에게 input()으로 값을 입력받을 때는 기본적으로 모두 문자열(str)로 인식하기 때문에, 숫자로 계산을 하려면 반드시 형변환(int(), float())을 해줘야 합니다. 수익률 계산에는 소수점이 포함 되기 때문에 실수형인 float형을 사용하여야 합니다. (아래는 제미나이가 만들어준 변수와 자료형을 제 시나리오에 맞춘 것입니다.)
stock_name (str - 문자열): 종목명
buy_price (int - 정수): 매수 단가
current_price (int - 정수): 현재가
quantity (int - 정수): 보유 수량
return_rate (float - 실수): 수익률

## 🟩 [2차 과제: V1.0] 입출력 + 리스트 + 조건문 - 향후 작성 예정
### **✨2차 과제 내용:**
(예시)
  * 이번 과제는 주식 사용자로부터 데이터를 입력받아  저장하고, 수익률 계산후
  *  결과값을 도출하는 시스템을 구축하는 것입니다. 특히 `if-elif` 조건문과 `and/or` 논리 연산자를 활용하여  주식 수익률에 따른 사용자 등급, 매수 타이밍, 매도 타이밍을 알려주는 지능형 로직을 완성해야 합니다.
  * input()으로 사용자 이름, 매수한 주식이름, 매수 가격, 매수한 주식수등을 입력받아 리스트에 저장.
  * 수익률 공식을 적용하여 각 주식의 수익률과 전체 수익률을 계산: 수익률(%) = ((현재가 - 매수가) / 매수가)*100
  * if-elif-else를 사용하여 수익률에 따라 매도 매수 추천 문구 출력
  * and 연산자를 활용하여 '주식 고수' 등 특별 칭호 부여 기능 구현.
    
### **🤖 AI 파트너십 과정**
(예시) 
1. **내용 1: 길드 매니저 컨셉 및 로직 도출**
    * **프롬프트 요약:** "내가 주식 수익관리 프로그램을 만들 거야. 대학생 수준에서 리스트와 조건문을 활용해 추가해야 할 기능이나 보완해야할 것 짜줘."
    * **적용 내용:** AI가 제안한 조건문을 사용하여 수익률 상태 브리핑과 매수 매도 추천출력
    * 아이디어를 실제 코드에 반영함.

2. **내용 2: 효율적인 리스트 활용법 자문**
    * **프롬프트 요약:** "파이썬 기초 문법 단계(리스트 → 조건문 → 반복문 → 함수/딕셔너리)에 맞춰, 사용자의 주식 수익관리 컨셉의 프로그램이 어떻게 발전할 수 있을지 4단계 기능 확장 로드맵을 제안해줘."
    * **적용 내용:** 단순 입출력을 넘어, **'기초 정보 입력 및 리스트 저장(1차) → 수익률 계산 후 조건문 프로그램에 판단력 부여하기 (2차) →메인 메뉴(UI) 생성 및 포트폴리오 일괄 브리핑 기능을 추가 반복문을 이용하여 자동화(3차) → 딕셔너리를 활용한 다중 사용자 주식 수익관리(4차)'**로 이어지는 논리적인 확장 로드맵을 확립함.
    
### **🛠️ Troubleshooting & 기술 회고:**
(예시) 
1. **문제 1: int()로 숫자를 입력했는데 계산이 안 되는 현상 (TypeError)**
    * **원인:** `int()`로 입력한 숫자의 형태는 정수형이다 주식의 가격은 소수점이 존재하기에 정수형의 int로 변환하면 오류가 발생한다
    * **해결:** `float()` 함수를 사용하여 입력값을  실수형 숫자로 바꾸는 '형변환' 마법을 부려 해결함.
2. **문제 2: f스트링에서 변수의 값을 {}하지 않는 경우 (SyntaxError)**
    * **원인:**{ 하나만 쓰게되면 SyntaxError가 되고 빠트리면 변수명을 그냥 글자로 인식한다
    * **해결:** f스트링에서 변수의 값에는 항상 {}이 들어가야 한다는 규칙을 학습하고 수정함.
